# API reference

Living inventory of the DocuLens HTTP API as implemented in `apps/api`. The OpenAPI document
generated by FastAPI is the machine-readable contract; this page orients reviewers and operators.

**Source of truth for route presence:** `apps/api/tests/api/test_openapi.py` (`SPEC_PATHS`).  
**Requirements:** [`SPECIFICATIONS.md`](../SPECIFICATIONS.md) §33–§36.  
**Architecture:** [`architecture.md`](architecture.md).

## Viewing OpenAPI

| Environment | Behaviour                                                                          |
| ----------- | ---------------------------------------------------------------------------------- |
| Local       | `/docs` (Swagger UI) and `/openapi.json` when `API_DOCS_ENABLED` is unset or true  |
| Deployed    | Docs **off** by default; set `API_DOCS_ENABLED=true` only if intentionally exposed |

```bash
uv run uvicorn doculens_api.main:create_app --factory --reload --port 8000
# → http://127.0.0.1:8000/docs
# → http://127.0.0.1:8000/openapi.json
```

ReDoc is disabled (`redoc_url=None`). TypeScript clients in `packages/shared-types` are
**hand-maintained**, not generated from OpenAPI ([ADR-021](decisions/ADR-021-frontend-foundation.md)).

## Happy-path walkthrough

Automated (preferred): with API + worker up and `QUEUE_BACKEND=redis`,

```bash
uv run python scripts/demo_api_happy_path.py
```

Manual curl sketch (replace tokens and ids):

```bash
# Register + login
curl -sS -X POST http://127.0.0.1:8000/api/v1/auth/register \
  -H 'Content-Type: application/json' \
  -d '{"email":"reviewer@example.com","password":"correct horse battery staple"}'
curl -sS -X POST http://127.0.0.1:8000/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"reviewer@example.com","password":"correct horse battery staple"}'
# → access_token

# Upload PDF
curl -sS -X POST http://127.0.0.1:8000/api/v1/documents \
  -H "Authorization: Bearer $ACCESS" \
  -F 'file=@handbook.pdf;type=application/pdf'
# Poll GET /api/v1/documents/{id} until processing_status=READY

# Ask
curl -sS -X POST http://127.0.0.1:8000/api/v1/conversations \
  -H "Authorization: Bearer $ACCESS" -H 'Content-Type: application/json' -d '{}'
curl -sS -X POST http://127.0.0.1:8000/api/v1/conversations/$CID/messages \
  -H "Authorization: Bearer $ACCESS" -H 'Content-Type: application/json' \
  -d "{\"question\":\"How many days of annual leave?\",\"document_ids\":[\"$DOC\"]}"
# → assistant_message.content + assistant_message.citations[]
```

## Conventions

| Concern             | Implementation                                                                                                           |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Versioning          | Application routes under `/api/v1`; health under `/health`                                                               |
| Auth                | `Authorization: Bearer <access_token>` (HS256 JWT). No cookies on the API                                                |
| Refresh / logout    | JSON body `{ "refresh_token": "..." }` — not cookie transport                                                            |
| Errors              | `{ "error": { "code", "message", "request_id", "details?" } }` (§35)                                                     |
| Correlation         | Request ID from `REQUEST_ID_HEADER` (default `X-Request-ID`) or generated                                                |
| Cross-tenant access | Owner-scoped reads return **404** (same as missing), never 403 ([ADR-013](decisions/ADR-013-authorization-responses.md)) |
| Security headers    | `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Cache-Control: no-store`, locked CSP                    |

## Route inventory

### Health (unauthenticated)

| Method | Path            | Purpose                                                               |
| ------ | --------------- | --------------------------------------------------------------------- |
| GET    | `/health/live`  | Liveness                                                              |
| GET    | `/health/ready` | Readiness (DB, storage, queue, optional Chroma); **503** if not ready |

### Auth (unauthenticated, rate-limited)

| Method | Path                    | Purpose                         |
| ------ | ----------------------- | ------------------------------- |
| POST   | `/api/v1/auth/register` | Create account                  |
| POST   | `/api/v1/auth/login`    | Credentials → access + refresh  |
| POST   | `/api/v1/auth/refresh`  | Rotate refresh → new token pair |
| POST   | `/api/v1/auth/logout`   | Revoke refresh family; **204**  |

Login/register response shape: `{ access_token, refresh_token, token_type: "Bearer", expires_in }`.

### Users (Bearer)

| Method | Path               | Purpose      |
| ------ | ------------------ | ------------ |
| GET    | `/api/v1/users/me` | Current user |

### Collections (Bearer)

| Method | Path                                  | Purpose                                   |
| ------ | ------------------------------------- | ----------------------------------------- |
| POST   | `/api/v1/collections`                 | Create                                    |
| GET    | `/api/v1/collections`                 | List                                      |
| GET    | `/api/v1/collections/{collection_id}` | Get                                       |
| PATCH  | `/api/v1/collections/{collection_id}` | Update name/description                   |
| DELETE | `/api/v1/collections/{collection_id}` | Delete (documents/conversations detached) |

### Documents (Bearer)

| Method | Path                                        | Purpose                                                 |
| ------ | ------------------------------------------- | ------------------------------------------------------- |
| POST   | `/api/v1/documents`                         | Multipart PDF upload (`file`, optional `collection_id`) |
| GET    | `/api/v1/documents`                         | List; `collection_id`, `q` (filename substring)         |
| GET    | `/api/v1/documents/{document_id}`           | Metadata + processing status                            |
| PATCH  | `/api/v1/documents/{document_id}`           | Rename / move                                           |
| DELETE | `/api/v1/documents/{document_id}`           | Soft-delete saga                                        |
| POST   | `/api/v1/documents/{document_id}/reprocess` | Restart from `VALIDATING`                               |
| POST   | `/api/v1/documents/{document_id}/reindex`   | Restart from `CHUNKING` (pages must exist)              |

There is **no** document download/view endpoint and **no** semantic `POST /search` (**OQ-3**, **OQ-10**).

### Conversations (Bearer)

| Method | Path                                                      | Purpose                            |
| ------ | --------------------------------------------------------- | ---------------------------------- |
| POST   | `/api/v1/conversations`                                   | Create                             |
| GET    | `/api/v1/conversations`                                   | List (most recently updated first) |
| GET    | `/api/v1/conversations/{conversation_id}`                 | Get                                |
| PATCH  | `/api/v1/conversations/{conversation_id}`                 | Rename / move                      |
| DELETE | `/api/v1/conversations/{conversation_id}`                 | Delete (messages + citations)      |
| POST   | `/api/v1/conversations/{conversation_id}/messages`        | Ask (sync JSON answer + citations) |
| POST   | `/api/v1/conversations/{conversation_id}/messages/stream` | Ask via SSE (`text/event-stream`)  |
| GET    | `/api/v1/conversations/{conversation_id}/messages`        | History with citations             |

Ask body includes `question` (max length 100_000 at transport; effective retrieval length is
settings-capped) and optional document scope. Streaming persists the assistant turn **only** on a
successful final event ([ADR-018](decisions/ADR-018-answering-pipeline.md)).

## Rate limits and quotas (enforced)

Defaults from `ApiSettings` / `CoreSettings` (see [`.env.example`](../.env.example)):

| Budget                             | Default                      | Scope                                    |
| ---------------------------------- | ---------------------------- | ---------------------------------------- |
| Auth                               | 10 / 60s                     | Per client address; login also per email |
| Upload                             | 30 / 60s                     | User + IP                                |
| Ask (sync + stream)                | 30 / 60s; 500 / day          | Short: user+IP; daily: user              |
| AI ops (enqueue/reprocess/reindex) | 30 / 60s; 200 / day          | Same pattern                             |
| Document / storage / pages         | 100 docs; 5120 MB; 50k pages | Per-user live totals                     |
| Questions / AI cost                | 500 / day; $10 / day         | Daily UTC ledger (`usage_events`)        |

Deployed environments require `RATE_LIMIT_BACKEND=redis`. `X-Forwarded-For` is **ignored**; the
peer socket address is used so clients cannot spoof per-IP budgets.

## Upload constraints

| Setting                  | Local default | Deployed                                                    |
| ------------------------ | ------------- | ----------------------------------------------------------- |
| `MAX_FILE_SIZE_MB`       | 50            | Cap ≤ **10** MB (`DEPLOYED_MAX_FILE_SIZE_MB`) when deployed |
| `MAX_PAGES_PER_DOCUMENT` | 500           | Same knob                                                   |

API Gateway HTTP API body limits (~10 MiB) are why the deployed file-size cap is lower than the
local default ([ADR-020](decisions/ADR-020-document-upload-transport.md), **OQ-3**).
